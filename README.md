# French Tech Intel

Market intelligence dashboard tracking French startup fundraising, exits & M&A, investors, and PE portfolio exit timing.

## Restoration note

The original Vercel project (`french-tech-intel`) was accidentally linked to the `Fundex` GitHub repo and its production deployment got overwritten by Fundex pushes starting 2026-08-04. This repo restores the site from the last known-good Vercel deployment (`dpl_HbjqEWuGw3UcjkcsXcDNiejb3cnP`, built 2026-07-07) by capturing its served output — a single self-contained static `index.html` (no separate build step, no external API calls, no framework).

Sections: Levées de Fonds, Exits & M&A, Investisseurs, PE Watch, Comparables, Buyers.
